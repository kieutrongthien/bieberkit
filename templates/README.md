# Starter templates

Templates for `pnpm create bieberkit`: `blank`, `cms`, `crm` and `saas` (spec section 12). A template is a preset of plugins plus project files, never a fork of the framework.

`blank` arrives in Phase 1 with the pilot project. The others arrive in Phase 2.
