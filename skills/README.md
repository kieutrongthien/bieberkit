# Skills for generated projects

Agent Skills that `create-bieberkit` copies into every new project's `.agents/skills/` (spec section 22.1): `bieberkit-add-entity`, `bieberkit-add-module`, `bieberkit-add-workflow`, `bieberkit-write-tests`, `bieberkit-upgrade`.

They are written once the APIs they describe exist. Skills for working on this repository are in `/.agents/skills/` instead.
