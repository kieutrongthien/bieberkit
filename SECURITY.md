# Security policy

## Reporting a vulnerability

Please do not open a public issue for a security problem.

Report it privately through GitHub: open the repository's **Security** tab and choose **Report a vulnerability**. If that is not possible, email Bieber Kieu at kieutrongthien@gmail.com with "BieberKit security" in the subject.

Include the affected package and version, steps to reproduce, and the impact you expect.

## What to expect (SEC-20)

- A first response within 7 days.
- A fix or mitigation plan agreed with you, then coordinated disclosure within 90 days of the report.
- Credit in the advisory, unless you prefer to stay anonymous.

## Supported versions

| Line | Security fixes |
| --- | --- |
| Current major | Yes |
| Previous major | For 6 months after the next major ships |
| Older | No |

BieberKit has no published release yet.
