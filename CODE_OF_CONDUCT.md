# Code of conduct

BieberKit adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as its code of conduct (GOV-04).

Everyone who takes part in the project's issues, pull requests, discussions and other spaces is expected to follow it.

## Reporting

Report unacceptable behavior to Bieber Kieu at kieutrongthien@gmail.com. Reports are handled confidentially. The enforcement guidelines in the Contributor Covenant apply.
