# Data ORM and tenant (M1.2, slice 3) implementation plan

Design: `docs/modules/data.md`, section "Slice 3". The tests are written and wait for the maintainer's review. Implementation follows them, one task per area, each ending in one signed commit. Gates after every task on Node.js 26: `pnpm check`, `typecheck`, `lint`, `test`, with the database suites run on SQLite, PostgreSQL 15 and MySQL 8.4.

## Tasks

1. **Compiler** (`src/orm/compile.ts`): standard columns, field kinds, constraints, relations, composite tenant foreign keys, single tenancy, overrides. Tests: `compile.test.ts`, `compile.dialects.test.ts`.
2. **EntityManager and tenant** (`src/orm/entity-manager.ts`, `tenant.ts`, `connect.ts`): the filter, the bypass guard, `asSystem`, tenant fill and immutability. Tests: `tenant.test.ts`.
3. **References** (`src/orm/references.ts`). Tests: `references.test.ts`.
4. **Version** (`expectVersion`, the 412 mapping). Tests: `version.test.ts`.
5. **Soft delete and bulk helpers** (`softdelete.ts`, `bulk.ts`). Tests: `bulk.test.ts`, soft delete cases of `compile.dialects.test.ts`.
6. **Gates**: API report, changeset, ROADMAP ticks, coverage threshold stays at 90 percent.

## Stop

Slice 4 (queries) starts after slice 3 is reviewed and merged.
